# Abdul Lathief A H — Portfolio

A responsive, cinematic single-page AI/ML engineering portfolio focused on computer vision, real-world deployment, and full-stack work.

## Run locally

Open `Abdul Lathief Portfolio.html` in a browser. `index.html` redirects to the renamed page so the site still works as a folder or static-host entry point. You can also open this folder in VS Code and start it with the Live Server extension.

The site uses plain HTML, CSS, and JavaScript. Google Fonts are loaded from the web when available; system sans-serif and monospace fonts are used as fallbacks.

## Files

- `Abdul Lathief Portfolio.html` — main page content and structure
- `index.html` — default entry point redirecting to the named page
- `styles.css` — complete responsive styling and color theme
- `script.js` — mobile navigation, project filtering, project detail dialogs, and current footer year

The cinematic direction uses a viewport-fitted opening, staged wordmark reveal, ambient pointer-reactive canvas, gentle section snapping, scroll progress, scroll-triggered entrances, perspective project cards, and a cursor/click-controlled career timeline. Animated CSS scenes visualize Generative AI, CCTV/computer vision, and AI-agent workflow concepts. It takes interaction cues from the linked cinematic portfolio without reusing that creator’s video, artwork, or source assets. The AI workflow and project previews are original CSS/canvas compositions. The project descriptions are based on the profile details provided; AI deployment is featured first, with student and web projects as supporting work.
