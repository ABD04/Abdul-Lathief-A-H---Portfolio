# Abdul-Lathief-A-H---Portfolio

Portfolio of Abdul Lathief A H

## About

A responsive, cinematic single-page AI/ML engineering portfolio focused on computer vision, real-world deployment, and full-stack work.

## Run locally

Open `Abdul Lathief Portfolio.html` in a browser. `index.html` redirects to the named page so the site works from a static host. You can also open this folder in VS Code and use the Live Server extension.

The site uses plain HTML, CSS, and JavaScript. Google Fonts are loaded from the web when available, with system font fallbacks.

## Files

- `Abdul Lathief Portfolio.html` — main page content and structure
- `index.html` — default entry point
- `styles.css` — responsive styling and color theme
- `script.js` — mobile navigation, project filtering, project detail dialogs, and footer year
- `assets/images/abdul-lathief-portrait.png` — homepage portrait

The cinematic design uses a burgundy palette, Bodoni Moda display type, Geist body type, and JetBrains Mono labels. It includes a viewport-fitted opening, animated wordmark, pointer-reactive canvas, scroll reveals, interactive career timeline, and an original portrait treatment. CSS scenes visualize Generative AI, CCTV/computer vision, and AI-agent workflows. The portfolio project descriptions are based on the profile details provided.
